# 🎯 업다운(Up-Down) 알고리즘 탐색 및 성능 분석 웹 애플리케이션

> **정보 교과 알고리즘 및 문제 해결 단원 수업용 인터랙티브 교육 도구**  
> 학생들이 업다운 숫자 맞추기 게임을 통해 다양한 탐색 알고리즘의 동작 원리와 효율성(시간 복잡도, 시도 횟수)을 직관적으로 학습하고 분석할 수 있는 웹 기반 시뮬레이터입니다.

---

## 📌 주요 특징 및 기능

### 1. 🎮 인터랙티브 탐색 시뮬레이션 모드
- **정답 설정 및 단계별 실행**: 1부터 100까지의 자연수 중 정답을 지정하고, 5가지 서로 다른 탐색 알고리즘이 정답을 찾아가는 과정을 실시간 수직 수직선(Number Line) 및 카드 애니메이션으로 확인.
- **실시간 탐색 범위 시각화**: 업/다운 피드백에 따른 최소/최대 탐색 범위 축소 과정을 직관적인 그래픽으로 제공.
- **알고리즘 비교 분석**:
  1. **순차 탐색 (Sequential)**: 1부터 1씩 순서대로 확인 ($O(N)$)
  2. **이분 탐색 (Binary)**: 중간값을 기준으로 범위를 절반씩 축소 ($O(\log N)$)
  3. **무작위 탐색 (중복 제외)**: 과거 추측을 기억하고 제외하며 무작위 추측
  4. **무작위 탐색 (업/다운 반영)**: 피드백으로 축소된 범위 내에서 무작위 추측
  5. **무작위 탐색 (중복 포함)**: 아무 힌트 없이 매번 완전 무작위 추측 (이론상 무한)

### 2. 📊 대규모 반복 시뮬레이션 및 통계 분석 모드
- **1회 ~ 1,000회 일괄 시뮬레이션**: 다회차 반복 시행을 통해 알고리즘별 최소, 평균, 최대 시도 횟수를 통계적으로 산출.
- **Chart.js 기반 반응형 차트**: 최소 시도(Best), 평균 시도(Avg), 최악 시도(Worst)를 3개 병렬 수평 바 차트로 한눈에 비교.
- **한 화면 최적화 UI**: 스크롤 없이 시뮬레이션 컨트롤, 통계 요약표, 3개 비교 차트가 한눈에 들어오는 레이아웃.

### 3. 💡 정보 교과 개념 학습 슬라이드 모달
- **1단계**: 💻 컴퓨터를 활용한 문제 해결 5단계 과정 및 알고리즘 설계의 정의
- **2단계**: 💬 알고리즘의 5대 조건 (입력, 출력, 명확성, 수행 가능성, 유한성)
- **3단계**: 📝 알고리즘의 표현 방법 (자연어 & 의사 코드)
- **4단계**: 📊 알고리즘의 표현 방법 (순서도 기호와 의미 — 단말, 입출력, 처리, 판단, 흐름선)
- **5단계**: 🔍 알고리즘 설계 및 성능 분석 방법 (효율성, 수행 시간, 공간 복잡도)

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend**: HTML5, Vanilla JavaScript (ES6+), Vanilla CSS
- **Visualization & Charting**: [Chart.js (v4.4.1)](https://www.chartjs.org/)
- **Icons & Fonts**: [Font Awesome (v6.4.0)](https://fontawesome.com/), Google Fonts (Inter, Outfit)
- **Deployment**: [Vercel](https://vercel.com/) (정적 웹 호스팅)
